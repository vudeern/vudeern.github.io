ECG Time-Series Classifier

I used a convolutional network to read patterns across an ECG recording and assign a rhythm category. The model reached 73.60% accuracy on the validation split.

Python / Keras / TensorFlow / 1D CNNSource code on GitHub ↗

Input & preparation

Each example is a 2,000-sample signal. I held out 20% of the data for validation and reshaped the recordings into the format required by a 1D convolution. The labels cover four target categories, with a separate unknown-category output in the encoding.

Model architecture

The network reads the signal through four convolutional layers, using progressively smaller kernels: 15, 9, 5, then 3. Pooling reduces the sequence length, while normalization and dropout help control training before the final classification layers.

Training & results

I trained with Adam, starting at a learning rate of 0.0005. Training slows when validation loss stalls and stops when validation accuracy no longer improves. Training accuracy was 79.83%, compared with 73.60% on validation; that gap is part of evaluating the result, alongside the accuracy itself.
